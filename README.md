# 🚀 CS Ultimate Curriculum Tracker

A high-performance, visually stunning learning management tool designed for ambitious engineers transitioning from **Full-Stack Development to Machine Learning Engineering**. 

Built with a modern **Glassmorphism** aesthetic, this tracker helps you navigate a rigorous 80-week computer science curriculum with precision and style.

---

## ✨ Features

### 💎 Modern Glassmorphic UI
- **Translucent Interfaces:** High-end design with backdrop-blur effects and subtle gradients.
- **Dynamic Background:** A smooth, animated gradient mesh that responds to your system's dark/light mode.
- **Responsive Layout:** Perfectly optimized for both focused desktop study sessions and quick mobile check-ins.

### 📚 Comprehensive Curriculum
- **5-Phase Roadmap:** From CS Foundations to advanced AI/ML Engineering.
- **Granular Tracking:** Track progress at the Subject, Topic, and Project levels.
- **Resource Hub:** Curated links to the world's best free and paid resources (MIT OCW, CS50, Harvard, etc.).

### ⏱️ Deep Focus Tools
- **Pomodoro Session Timer:** Integrated timer with "Deep Focus" mode to keep you in the flow.
- **Automatic Logging:** Work sessions are automatically attributed to your current subject and logged to your analytics.
- **Streak System:** Gamify your learning with a daily study streak tracker.

### 📊 Advanced Analytics
- **Visual Progress:** Beautifully rendered charts (Pie, Bar, and Line) showing your completion rate and study trends.
- **Time Distribution:** See exactly where your hours are going across different phases of the curriculum.
- **Study Trends:** Monitor your activity over the last 30 days to maintain consistency.

### 💼 Career Engineering
- **Job Strategy:** Localized advice for the Philippine tech market.
- **Portfolio & Resume Tools:** Shortcuts to builders and optimizers to help you get hired.

---

## 🛠️ Tech Stack

- **Frontend:** React 18 with TypeScript
- **Styling:** Tailwind CSS (Custom Glassmorphism utilities)
- **State Management:** Zustand (Persistent LocalStorage)
- **Icons:** Lucide React
- **Charts:** Recharts
- **Build Tool:** Vite

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher)
- npm or yarn

### Installation

1. **Clone the repository:**
   ```bash
   git clone <your-repo-url>
   cd cs-curriculum-tracker
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run in development mode:**
   ```bash
   npm run dev
   ```
   The site will be available at `http://localhost:3000`.

4. **Build for production:**
   ```bash
   npm run build
   ```

---

## 📖 How It Works

1. **Set Your Focus:** Go to the **Planner** tab to select which subjects you intend to master this week.
2. **Ignite Focus:** Open the **Floating Timer** (bottom-right), select your current mission, and start your Pomodoro.
3. **Mark Milestones:** As you finish topics or projects, check them off in the **Curriculum** tab.
4. **Analyze Growth:** Visit the **Analytics** tab once a week to review your study patterns and ensure you're on track for your 80-week goal.
